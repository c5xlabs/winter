# winter

The Winter platform CLI launcher: a Rust workspace whose public executable is `winter`.

- Run this checkout through `./scripts/winter-cli` or `cargo dev …`, never through an installed `winter`, which is the
  separate workspace tool.
- Run `cargo dev check` before pushing.
- Read [context/index.md](./context/index.md) before implementing, reviewing code, or reviewing architecture.
